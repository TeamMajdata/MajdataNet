# 编辑器的右键菜单键盘操作、快捷键说明与方向键跳转

日期：2026-11-27
分支：`main`

## 背景

- 上一版加的右键菜单只能用鼠标点：打开后菜单不拿焦点，`↑/↓/Enter` 都落进 Monaco；
  顺序也不顺手（撤销/重做在最前）；
- 快捷键说明窗里没有 `=`，也没写 `Shift + ← / →` 是干什么的；
- 按格跳转只认 `Ctrl + ← / →`；`Ctrl + ↑ / ↓` 被 Monaco 自带的「滚动」吃掉；
- **输入法拦截实测没用**：浏览器没有关闭 IME 的 API，「失焦取消组词」在真实输入法下不稳定，
  组词照样能进谱面。按反馈直接移除，不再尝试。

## 前端改动

| 位置 | 改动 |
| --- | --- |
| `src/components/editor/EditorContextMenu.tsx` | 顺序改为 **镜像 5 项 → 撤销 / 重做**；打开时自己拿焦点，`↑` / `↓` 移动（跳过不可用项）、`Enter` / `空格` 执行、`Esc` 收起；鼠标悬停同步高亮；默认落在第一个可用项 |
| `src/components/editor/SimaiCodeEditor.tsx` | 移除 `compositionstart` / `beforeinput` 的输入法拦截和对应日志（保留右键上报、`=` 的 keybinding）；`Ctrl + ←/→/↑/↓` 改用 `editor.addCommand` 注册，盖掉 Monaco 自带的「Ctrl+上下 = 滚动」「Ctrl+左右 = 按词移动」 |
| `src/pages/EditorPage.tsx` | 跳转拆成两个方向：**左右按逗号格子**跳（`→` 下一格、`←` 上一格），**上下按行**跳（保持列，超出就贴行尾），两者都会把播放头跳到落点所在格子的时间；逻辑抽成 `jumpCell`，页面级 keydown 只兜住焦点在编辑器外面的情况（`defaultPrevented` 时跳过，避免跳两次）；快捷键列表新增 `Ctrl + ↑ / ↓`、`Shift + ← / →`、`=` 三行；弹菜单前重读一次选区，收起后把焦点还给编辑器 |
| `src/locales/{zh,en,ja,ko}.json` | 新增 `ShortcutSelect`、`ShortcutContextMenu`、`ShortcutLine`；`ShortcutNote` 改为「按逗号格子移动光标并跳到那一刻」 |

## 快捷键窗里现在写着

| 键 | 作用 |
| --- | --- |
| `Ctrl + ← / →` | 按逗号格子移动光标并跳到那一刻 |
| `Ctrl + ↑ / ↓` | 跳到上一行 / 下一行（保持列，并跳到那一行的时间） |
| `Shift + ← / →` | 扩展 / 收缩选区（镜像只作用于选区） |
| `=` | 打开菜单：镜像 / 撤销 / 重做（在光标下方弹出，不会插入 `=`） |

## 验证

浏览器（真实谱面 + `?debug=1`，焦点都在编辑器里）：

- `Ctrl + ↓`：光标一行一行往下走（`top 12 → 30 → 48px`），时钟跟着跳到那一行的时间
  （`0:00 → 0:04`），编辑器 `scrollTop` 保持 0 —— 不再被 Monaco 解释成滚动；
- `Ctrl + ↑`：按行回退（`48 → 30px`）；
- `Ctrl + →` / `Ctrl + ←`：仍在逗号格子之间跳（`left 0 → 56px`），跨行时会落到下一行的格子上；
- 单次按键只跳一次（页面级 keydown 与 Monaco 命令不会重复触发）；
- 快捷键窗共 12 行，顺序与文案正确（含 `=`、`Shift + ← / →`、`Ctrl + ↑ / ↓`）；
- 右键菜单：顺序为镜像 5 项 + 撤销/重做，`↑/↓` 在可用项之间移动，`Enter` 执行撤销并关闭、
  焦点回到编辑器，`Esc` 同样收起并回焦；没有选区时镜像灰、有选区时变亮并可执行；
- 输入法：拦截代码已删干净（`grep composition` 无结果），组词不再被页面干预。

`pnpm lint`、`tsc -b`、`pnpm i18n:check` 通过。

## 注意

- `=` 仍由 Monaco 的 keybinding 拦截，只在编辑区里生效。
- 上下跳行是「保持列」的：目标行比原列短时贴到行尾；空行也算一行，落上去后时间会停在前一格。
- 输入法要输入中文/日文注释时，需要自己切回中文输入；页面不再做任何拦截。
