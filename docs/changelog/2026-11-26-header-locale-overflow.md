# 顶栏在英语 / 日语下溢出（导航压到搜索和账号上）

日期：2026-11-26
分支：`main`

## 背景

顶栏容器是 `max-w-320`（80rem = 1280px），所以不管窗口多宽，可用宽度都只有 1270px 左右。
主导航有六项、文案不收缩（`xl:whitespace-nowrap`），en/ja 的文案比中文长，直接压到右侧的
搜索框、语言菜单和登录按钮上。

实测（1440px 窗口，容器仍是 1280px）：

| 语言 | 导航右边缘 | 右侧控件左边缘 | 结果 |
| --- | --- | --- | --- |
| zh | 600 | 696 | 不重叠，余 96px |
| en | 821 | 743 | 重叠 78px |
| ja | 954 | 734 | 重叠 220px（`ヘビープレイヤーランキング` 单项 208px） |

收紧间距（padding 12→8、gap 2→0、搜索框 288→240）最多省 110px：en 能救回来，ja 还差 50px。
因为容器封顶，加宽窗口也不会变好，所以必须动文案和导航结构。

## 前端改动

| 位置 | 改动 |
| --- | --- |
| `src/components/header/navigationItems.ts` | 主导航六项改五项：`文档` 收进 `工具` 下拉（外链仍在新标签页打开） |
| `src/locales/ja.json` | `shared/Navigation`：`ヘビープレイヤーランキング` → `ヘビープレイヤー`，`コレクション広場` → `コレクション` |
| `src/components/header/Navigation.tsx` | xl 间距收紧（`px-3`→`px-2.5`）；导航项允许收缩（`min-w-0`），标签 `xl:truncate`，万一以后再长也只是省略号，不会盖住右侧 |
| `src/components/header/index.tsx` | 左侧 Logo 与导航的间距 `xl:gap-4`（去掉 `2xl:gap-8`：容器不跟着变宽，间距变大只会挤压导航） |
| `src/components/header/HeaderSearch.tsx` | 桌面搜索框 `xl:w-72` → `xl:w-60`（288→240px） |

改完后各语言在 1270px 可用宽度下的余量：zh 243px、ko 71px、en 68px、ja 31px，均无截断。

## 验证

- 新增 `e2e/header-layout.spec.ts`：4 种语言 × 1280/1920 窗口，断言主导航右边缘在右侧控件左边
  （`gap > 0`）、页面没有横向溢出、5 个主导航项都没有被截断；另有手机端菜单项与 `工具` 子项检查。
- 新增 `test/components/header/Navigation.test.tsx` 断言：顶层只有 5 项、`文档` 在 `工具` 下面。
- 浏览器手测（1440px）：zh / en / ja / ko 顶栏均不重叠，`工具` 下拉里是「谱面编辑 / 谱面游玩 / 文档」。

## 注意

- 顶栏是 1280px 封顶的容器，**文案长度是有预算的**：以后再加导航项，先量一遍 en/ja；标签现在有
  `xl:truncate` 兜底，但省略号不是设计意图，只是防止再次重叠。
- `文档` 从顶层挪进 `工具` 后，外链的 `↗` 和 `target="_blank"` 行为保持不变，`Navigation` 的
  路由高亮逻辑没动（外链本来就不会被点亮）。
