## 1. 数据模型

### 1.1 maidata.txt 字段

| 字段 | 粒度 | 由谁编辑 | 备注 |
|---|---|---|---|
| `&title` / `&artist` | 全局 | 谱面信息窗 | |
| `&first` | 全局 | **中栏 First** | 播放器侧另有「First 偏移」，只存本地，不写文件 |
| `&first_N` | 逐难度 | 不提供编辑 | 读取优先于 `&first`：`first_{n+1} ?? first` |
| `&lv_N` | 逐难度 | 中栏「难度」 | 仓库夹具已确认：`&lv_4=12`、`&lv_5=14` |
| `&des_N` | 逐难度 | 中栏「制谱人」 | 号段与 `inote_N` 相同（1-based） |
| `&inote_N` | 逐难度 | **编辑器主体** | 编辑器里只放这一段的正文 |
| 其它 `&xxx` | 全局 | 谱面信息窗 | 通用 `&k=v` 列表 |

`N` = 难度索引 + 1，即 EASY→1 … UTAGE→7。

### 1.2 内存模型

```
maidata: string            整份文件原文（保存时的唯一真源）
draft[i]: string           第 i 个难度的 fumen 草稿（切页签不丢）
active: 0..6               当前难度
origin: string             上次保存时的 maidata 快照，用于逐难度判脏
dirty[i]: boolean          第 i 个难度相对上次保存有改动 → 页签显示 `*`
dirtyGlobal: boolean       全局字段（title / artist / &first / &commands）有改动
```

- 编辑器只认 `draft[active]`，保存时 `replaceDifficulty(maidata, active) = draft[active]` 拼回去。
- **脏按难度分开记**：哪一档改过，就只有那个页签带 `*`。
- 右上角胶囊 = `any(dirty) || dirtyGlobal`。
- 中栏的 `&lv_N` / `&des_N` 属于当前难度，算进 `dirty[active]`；`&first` 属于全局，算进 `dirtyGlobal`。

## 2. 六条决策

| # | 问题 | 决定 | 理由 |
|---|---|---|---|
| 1 | 变换时无选区 | **不响应**（跟随上游） | 有选区只改变选区，无选区时按钮不产生任何效果。避免误触整篇 |
| 2 | `First` 的落点 | 写全局 `&first` | 跟随上游；逐难度 `&first_N` 只读不写，避免出现两个入口 |
| 3 | ■ 在暂停时 | **停止并回到起点**（偏离上游） | 上游「暂停→继续播放」反直觉 |
| 4 | 切难度页签时有未保存改动 | **直接切，草稿留内存**；页签上标 `*` | 每个难度独立记脏，切回来内容还在 |
| 5 | 自动保存 | **要**，落 IndexedDB（`.autosave`），**脏状态不清零**（偏离上游） | 上游自动保存后清脏，用户会误以为已写进 `maidata.txt` |
| 6 | 播放是否用未保存文本 | **用**（保留上游行为） | 这就是「即时预览」的全部意义 |

### 3.2 编辑菜单的变换

- 作用于 Monaco 的选区，**无选区时不响应**（决策 1）。
- 实现：`editor.executeEdits` 替换选区文本，单步可撤销。

**映射不用查表，直接在角度空间推。** `geometry.js` 已经定义了 `laneAngle(i) = (i - 0.5) × 45°`（lane 1 在上右，顺时针）。把五种操作当成角度变换，再反解回 lane：

| 操作 | 角度变换 | lane 1..8 → | 代数式 |
|---|---|---|---|
| 水平镜像 | θ → −θ | 8 7 6 5 4 3 2 1 | `9 − i` |
| 垂直镜像 | θ → 180° − θ | 4 3 2 1 8 7 6 5 | `((4 − i) mod 8) + 1` |
| 180° | θ → θ + 180° | 5 6 7 8 1 2 3 4 | `i + 4` |
| 旋转 +45° | θ → θ + 45° | 2 3 4 5 6 7 8 1 | `i + 1` |
| 旋转 −45° | θ → θ − 45° | 8 1 2 3 4 5 6 7 | `i − 1` |

- 触控区 A/B/D/E 共用同一套索引；`sensorPoint` 里 D/E 额外减 0.5 偏移，变换后要补回去。`C` 不动。
- **slide 的方向符号按"是否翻转手性"处理**：镜像（后三种之外的 LR/UD/180）翻转手性 → `<`↔`>`、`p`↔`q`、`pp`↔`qq`、`s`↔`z`；旋转保持手性 → 符号不变。
- `V` 的 via 参与同一套 lane 变换；`^` 由 start + relative 决定，镜像后仍是 `^`。

**验证手段**：`slideShape()` 是现成的判定器 —— 变换后再跑一遍，比对几何是否等于原图按对应轴镜像的结果；另外可用"镜像两次 == 恒等""旋转 8 次 == 恒等"做自洽测试。这比照抄一份 C# 映射表更靠得住。

> 调研结论：`SimaiMirror` **不在** MajdataEdit-Neo（`Utils/` 只有 `MessageBox.cs`），也不在 MajSimai（`Runtime/Utils/` 无此文件）；它是 `MajdataPlay.View` 里的类型（ViewModel 顶部 `using MajdataPlay.View.Types;`）。所以本来也抄不到，上面这套是唯一可落地的路径。

### 3.3 难度页签

- 7 个常驻（EASY / BASIC / ADVANCED / EXPERT / MASTER / RE:MASTER / UTAGE），空档位也在。
- 点击 → 切 `active` → 换 Monaco model → 预览重建。
- 每个难度独立撤销栈。
- **脏标记显示在页签上**：该难度有未保存改动 → 名字后面跟一个 `*`（如 `MASTER *`）。
- 切走不提示（决策 4）。

### 3.4 中栏

| 控件 | 写入 | 交互 |
|---|---|---|
| 时间 `1:17` | 只读 | 跟随播放位置 |
| 难度 | `&lv_N` | 失焦/回车提交；空档位禁用 |
| 制谱人 | `&des_N` | 同上 |
| First | `&first` | 数值步进，步长 0.01 |
| 文本跟随 | 内存开关 | 播放时编辑器滚到当前行 |
| ■ / ▶ | — | 见 3.6 |

### 3.5 编辑区

| 交互 | 行为 |
|---|---|
| 输入 | 120–200ms 合并 + rAF 后重编译；实测 1000 物量 1.8ms、4000 物量 5ms |
| 解析失败 | **保留上一版正确谱面继续渲染**，只出非阻塞提示条；绝不清屏 |
| 当前难度为空 | 不算错误：编辑器空白，预览显示默认底图 |
| 光标移动 | 找最近的逗号时机 → 时间轴跳过去（文本跟随开或 Ctrl+点击时） |
| 悬停/点击时间轴 | 反查文本位置 → 编辑器滚到对应行 |

### 3.6 播放状态机

```
idle ──加载谱面──▶ ready ──▶ buffering ──▶ playing ⇄ paused
  ▲                  │                        │
  └── 换难度/换文件 ──┘                        └── ■ → ready（回起点）
```

| 按键 | 播放中 | 暂停 | 停止 |
|---|---|---|---|
| 播放键 | 暂停 | 继续 | 从当前时间播（用未保存文本） |
| 停止键 | 停止+回起点 | 停止+回起点 | 从头播 |

- 图标全部用 **SVG**（停止 / 播放 / 暂停），不用字符。
- **播放中播放键换成暂停图标**，暂停/停止时换回播放三角。

### 3.7 左盘（MajView）

- 未播放 / 空难度 → `Default_Background.png`；播放中 → 曲子 `bg.jpg`。
- 物量浮层：左上（物量/达成率/最大）、左下（分类），位置照 `majview.css` 的 `.majview-counter`。
- 右上单个全屏按钮。

### 3.8 时间轴（SimaiVisualizerControl）

| 交互 | 行为 |
|---|---|
| 滚轮/拖拽 | 改播放位置，同时把编辑器滚到对应行；拖动时暂停 |
| `+` / `−` | 缩放 0.1–10，默认 4 |

### 3.9 浮动窗

统一壳：**居中、可拖标题栏、无遮罩**（不阻塞编辑器）。

| 窗 | 模态 | 关闭时 |
|---|---|---|
| BPM Tap | 否 | 丢弃 |
| 设置 | 否 | 写 localStorage |
| 谱面信息 | 是 | 写回 title/artist/commands → 重载 bg/pv |
| 查找替换 | 否 | — |

### 3.10 保存与脏状态

```
dirty[i] / dirtyGlobal ──Ctrl+S──▶ 全部清零
        │
        └─ 自动保存（IndexedDB `.autosave`）→ 仍然 dirty
```

- 页签：该难度脏 → `MASTER *`。
- 右上角胶囊：`已保存`（绿）/ `未保存`（琥珀），有任一脏即为未保存。
- 新建、打开文件夹、关闭页面前：`AskSave`（存 / 丢弃 / 取消）。
- 自动保存：编辑停止 5s 后 debounce，另每 30s 兜底。
  - 落在 **IndexedDB**（键 = 目录名 + 文件名），命名延续上游的 `.autosave` 概念。
  - 内容是**整份 maidata 文本 + 当前难度 index**。
  - 打开时若草稿比磁盘文件新，提示「恢复上次编辑？」。
  - **自动保存不改变脏状态**（决策 5）。

## 4. 文件读取

| 角色 | 查找顺序 |
|---|---|
| 谱面 | `maidata.txt` |
| 音轨 | `track.ogg` → `track.mp3` |
| 背景 | `bg.jpg` → `bg.png` |
| PV | `pv.mp4` → `bg.mp4` |

- 首选 `showDirectoryPicker({ mode:'readwrite' })`；兜底 `<input webkitdirectory>`（只读）。
- 媒体一律 `URL.createObjectURL`，**每个文件保持稳定**（`audioBuffer` 按 URL 字符串缓存，URL 变了就重新解码整首歌）。

## 5. 与上游的差异

| 项 | 上游 | 我们 | 为什么 |
|---|---|---|---|
| 预览进程 | 独立 MajdataView + WebSocket | 页面内 MajView | 少一个进程/协议 |
| Connection 开关 | 有（连播放器） | 去掉 | 不需要 |
| `IsPlayControlEnabled` | 异步期间禁用按钮 | 去掉 | 解析同步，无往返 |
| ■ 暂停时 | 继续播放 | 停止回起点 | 决策 3 |
| 自动保存后 | 清脏 | 保持脏 | 决策 5 |
| 自动保存位置 | 本地 `.autosave/` 目录 | IndexedDB | 浏览器无任意文件写 |
| 七档名 | ORIGINAL | UTAGE | 跟 MajdataPlay |
| 状态显示 | 标题栏 `*` | 页签 `*` + 右上胶囊 | 无标题栏，且脏按难度分开 |
| 文件菜单 | 另存为 / 导出视频 / 上传 | 暂不提供 | 本期范围 |

## 6. 待验证 / 风险

1. **`&des_N` 的实际键名**：你已确认为与 `inote_N` 同号，但仓库内无样例夹具，实现后要用真实谱面回归一次。
2. **`simaiMirror` 的边界情况**：主映射已用角度模型推导并验证（见 3.2），剩下的是零散语法：`w`（wifi）的方向判定、`C`（中心触控）、`$`（mine）、`h`/`[speed]` 等修饰符要原样透传不能误伤。建议先做一版「只改变位置 token、其余字符原样偏移」的实现，用 `slideShape` 做几何比对回归。
3. **Monaco model 生命周期**：7 个难度各一个 model，切换时 `setModel`；销毁要配平，否则内存与撤销栈会串。
4. **File System Access 兼容性**：仅 Chromium；Safari/Firefox 只能退化成多选文件。
5. **自动保存的判定**：草稿比文件新的比较依据（时间戳 or hash）需要定；建议存 hash。
